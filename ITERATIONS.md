# 15 итераций разработки по TDD

На каждой итерации повторяем цикл:

1. **RED** — сначала добавляем новый тест, запускаем его и видим ошибку.
2. **GREEN** — пишем минимальный код, чтобы новый и старые тесты прошли.
3. **REFACTOR** — при необходимости упрощаем код и снова запускаем тесты.

**Важно:** файлы в ветке main — готовая версия. История загрузки готового проекта **не является доказательством** 15 циклов RED → GREEN → REFACTOR. Для демонстрации процесса нужно повторять эти шаги, например в отдельной ветке, и делать коммиты.

## Пример: первая итерация

**RED:** сначала создаём файл с тестом:

```python
from payment import Order

def test_01_create_order():
    order = Order()
    assert order.status == "new"
```

Запускаем `python -m pytest -v`. До реализации класса Order тест не пройдёт.

**GREEN:** создаём `payment.py`:

```python
class Order:
    def __init__(self):
        self.status = "new"
```

Теперь тест проходит. **REFACTOR:** если улучшать нечего, оставляем код без изменений.

Дальше открываем тест № 2 и повторяем процесс.

## Что показывать преподавателю

- `tests/test_payment.py` — 15 тестов;
- `payment.py` — итоговый код системы;
- вкладку **Actions** — автоматический запуск всех тестов;
- `ITERATIONS.md` — описание 15 этапов;
- отдельные коммиты RED и GREEN, **если вы действительно воспроизвели этапы**.
