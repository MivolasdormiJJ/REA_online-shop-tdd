# Онлайн-магазин — версия 2: стиль TDD Роберта Мартина

Это **тот же вариант 7 (онлайн-магазин)**, а не боулинг. Отличие от первой версии — максимально короткие тесты и реализация по принципу «ровно столько кода, сколько нужно для очередного теста».

Код написан на **Python**, комментарии — **на русском**.

## Файлы

- [shop.py](shop.py) — учебная система корзины и оплаты.
- [test_shop.py](test_shop.py) — 15 небольших тестов, от простых к сложным.
- [TDD_STEPS.md](TDD_STEPS.md) — порядок шагов RED → GREEN → REFACTOR.

## Запуск из корня репозитория

```bash
python -m pip install -r requirements.txt
python -m pytest -v martin_style_shop
```

Все 15 тестов должны пройти.

## Пример

```python
from martin_style_shop.shop import Shop

shop = Shop()
shop.add(500, 2)               # Два товара по 500 руб.
shop.set_discount(10)          # Скидка 10%
shop.set_payment_method("card") # Выбираем условную оплату картой
print(shop.total())             # 900.0
print(shop.pay(1000))           # 100.0 — остаток условного баланса
```

Никакие деньги не списываются — платёж здесь только имитируется.
