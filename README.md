# Практическая работа № 4 — TDD (вариант 7)

**Тема:** учебная система оплаты интернет-магазина. **Язык:** Python. **Тесты:** pytest.

> ⚠️ Оплата только имитируется: настоящие банковские операции и списания денег не выполняются.

## Что демонстрирует проект

В TDD (Test-Driven Development) сначала создают тест, а только затем пишут код:

1. 🔴 **RED** — новый тест не проходит, потому что функциональность ещё не реализована.
2. 🟢 **GREEN** — пишем минимальный код, необходимый для прохождения теста.
3. 🔵 **REFACTOR** — упрощаем код, не ломая существующие тесты.

Это повторяется **15 раз**, от создания пустого заказа до истории оплаты и возврата.

## Структура проекта

| Файл | Для чего нужен |

| [ITERATIONS.md](ITERATIONS.md) | Список 15 итераций и подробный пример RED → GREEN |

| [requirements.txt](requirements.txt) | Зависимость pytest |

## Как запустить

Можно открыть репозиторий через **Code → Codespaces → Create codespace on main**, без установки программ.

В терминале выполнить:

```bash
python -m pip install -r requirements.txt
python -m pytest -v
```

Ожидаемый результат: **15 passed**.

## Пример использования

```python
from payment import Order

order = Order()  # Создаём заказ
order.add_item("Книга", 500, 2)  # Две книги по 500 рублей
order.set_discount(10)  # Скидка 10%
order.set_payment_method("card")  # Условная оплата картой

print(order.total())  # 900.0
print(order.pay(1000))  # 100.0 — остаток условного баланса
print(order.status)  # paid
```

## Как смотреть результаты на GitHub

Перейти во вкладку [Actions](../../actions). Там проверяются все 15 тестов после каждого обновления кода.

## Важное замечание о TDD

В ветке `main` размещены **готовый код и 15 тестов**. История коммитов загрузки итогового проекта **не доказывает**, что тесты первоначально писались до реализации. Для полноценной демонстрации процесса RED → GREEN → REFACTOR воспроизведите изменения по [ITERATIONS.md](ITERATIONS.md) в отдельной ветке с раздельными коммитами. Не следует выдавать публикацию готового решения за проведённые 15 исторических циклов TDD.
